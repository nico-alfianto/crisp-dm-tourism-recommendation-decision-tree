Project Overview

Indonesia's tourism industry generates massive amounts of data, making it difficult for travelers to choose destinations efficiently. This project applies the CRISP-DM framework together with a Decision Tree Classifier to classify and recommend tourism destinations based on user ratings from a public Kaggle dataset. The goal is not to claim high accuracy, but to demonstrate a complete CRISP-DM workflow — from business understanding to evaluation — and to honestly analyze why a simple Decision Tree struggles on this dataset.

Honest Evaluation — Why 41%?

41% is not hidden. Here is what it actually means.

Best Recall: Medium class — 80%
The model is good at recognizing Medium-rated destinations because Medium is the majority class in the dataset.

Weak on Low & High
Minority classes are underrepresented, so the tree tends to predict Medium by default.

What this proves
A single Decision Tree is a good baseline, but not enough for a real recommender.

Suggested Improvements
Feature Engineering
Random Forest (ensemble, reduces overfitting)
Collaborative Filtering (user-based)
Hybrid Recommendation Systems
Class balancing / more data for Low & High

Methodology — CRISP-DM Framework

6 phases, end to end.

1. Business Understanding — Information overload in tourism destination selection.
2. Data Understanding — 3 tourism datasets from Kaggle, analyzed for structure & quality.
3. Data Preparation — Merge datasets, handle missing values, encode categorical features.

4. Modeling — Decision Tree Classifier using scikit-learn.
5. Evaluation — Confusion Matrix + Classification Report.
6. Deployment — Classify destination ratings into Low, Medium, High.
